# Claude Agents

Jede Domain hat einen eigenen Router (`AGENT.md`). Lies den passenden Router zuerst, bevor du in dieser Domain antwortest oder einen Subagenten startest. Alle Pfade dort sind relativ zum jeweiligen Domain-Ordner.

| Domain | Wofür | Router |
|---|---|---|
| Trainingsplanner | Trail- und Ultramarathon-Coaching auf ein Zielrennen hin | [`trainingsplanner/AGENT.md`](trainingsplanner/AGENT.md) |
| Shopping Helper | Kaufentscheidungen basierend auf einem persönlichen Profil | [`shoppinghelper/AGENT.md`](shoppinghelper/AGENT.md) |
| Vacation Finder | Ferienwohnungen und Unterkünfte finden | [`pensionfinder/AGENT.md`](pensionfinder/AGENT.md) |
